Current Behavior Highlights (Simulation 02)
- Two modes: Continuous and Phase Mode. Mode button toggles between them.
- Initial state: mode button text is "Phase Mode"; phaseMode = false; Next Phase disabled.
- Clicking Mode enables Phase Mode, enables Next Phase, and changes text to "Continuous".
- Next Phase steps through discrete gait keyframes in a loop.
- Direction button text shows the *next* direction (semantics flipped):
  - "Forwards" displayed => moveForward is false (backward motion active)
  - After click, moveForward becomes true and button shows "Backwards"
- moveForward affects hipX direction and which gait keyframe table is used.

Gait Keyframes
- GAIT_KEYS_FORWARD and GAIT_KEYS_BACKWARD are explicit arrays (no base mapping).
- Forward table uses negative knee values; backward is negated forward.

Animation / Rendering
- Walking view: left leg thigh blue, left knee segment brown, left foot green; right leg/foot black.
- Angle plots: hip blue, knee brown, ankle green (left leg only).
- Ground line is drawn at y = 0.

Recent Changes/Decisions

- Direction button remains label-only semantics (next action indicator).

Simulation 04 Summary
- Simulation 04 evolved from 03 with stronger parameterization and control behavior:
  - Human height support with derived segment lengths (L1, L2).
  - Derived step length linked to model geometry/angles.
  - Speed factor adjusted to affect playback rate (time) rather than changing spatial step size.
  - Improved continuity between Continuous mode and Phase mode (step/phase tracking preserved when switching modes).
  - Dynamic status text for current step and phase.
- Angle tables were iteratively corrected (especially ankle sign convention and typical PF/DF ranges).
- Final intent for 04: keep it stable as a validated baseline and branch new ideas into 05.

Simulation 06 Summary
- Simulation 06 was added as a separate supine leg-flexion variant, distinct from the gait simulations.
- Core motion model:
  - Single leg on a bed/table in lateral view.
  - Hip and knee are the active joints.
  - Foot remains constrained relative to the shank, and the leg cannot pass below the bed line.
- Joint constraints and kinematics:
  - Hip Y is fixed across the full cycle.
  - Knee angle is derived from hip angle through a selectable constraint factor.
  - Current selectable knee factors are `-2 x hip`, `-1 x hip`, and `0 x hip`.
- Geometry / anthropometry:
  - Foot geometry includes heel offset relative to the ankle joint instead of attaching directly at the heel.
  - Human height, L1, and L2 now work bidirectionally:
    - Changing height updates segment lengths using the current proportions.
    - Changing L1 or L2 directly re-estimates height from leg-length ratio and updates displayed percentages.
  - Direct numeric inputs were added for `Human height`, `L1`, and `L2`, alongside sliders.
- Rendering / layout:
  - Bed View now uses uniform metric scaling on X and Y, so visual angles and lengths are no longer distorted.
  - The page layout was compacted vertically and the controls were reorganized into a fixed desktop grid.
  - The current visible page label is `Version 06.6 - uniform bed scaling`.
