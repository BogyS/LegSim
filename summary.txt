Current Behavior Highlights (Simulation 02)
- Two modes: Continuous and Phase Mode. Mode button toggles between them.
- Initial state: mode button text is "Phase Mode"; phaseMode = false; Next Phase disabled.
- Clicking Mode enables Phase Mode, enables Next Phase, and changes text to "Continuous".
- Next Phase steps through discrete gait keyframes in a loop.
- Direction button text shows the *next* direction (semantics flipped):
  - "Forwards" displayed => moveForward is false (backward motion active)
  - After click, moveForward becomes true and button shows "Backwards"
- moveForward affects hipX direction and which gait keyframe table is used.

Gait Keyframes
- GAIT_KEYS_FORWARD and GAIT_KEYS_BACKWARD are explicit arrays (no base mapping).
- Forward table uses negative knee values; backward is negated forward.

Animation / Rendering
- Walking view: left leg thigh blue, left knee segment brown, left foot green; right leg/foot black.
- Angle plots: hip blue, knee brown, ankle green (left leg only).
- Ground line is drawn at y = 0.

Simulation 05 Summary (Current Active Variant)

- Foot model updates:
  - Added toe-break (MTP) point and separate toe segment.
  - Updated foot split so toe segment is shorter at 1.8 m (ankle->MTP ~0.16 m, MTP->toe ~0.105 m).

  - Added thin solid hip trajectory line in the Walking View.
- View/layout tuning:
  - Walking/angles canvas height alignment and compacted top controls/header spacing.

Latest Updates (English Notes)
- Pelvis plot now uses:
  - Uniform X/Y scaling,
  - Mouse hover readout (frame, phase, y),
  - Thin vertical cursor line at hovered X,
  - Fixed canvas height (300 px) to prevent resize drift.
- Simulation 05 hip translation was updated again:
  - Hip Y is now computed so the global lowest leg point (across both legs) stays exactly at `groundMargin` each frame.

- Expected side effect of the new rule:
  - Hip Y can drop below `L1 + L2` (for 1.80 m, minimum around 0.8515 m),
  - The curve can show sharp transitions where the active limiting contact point switches (piecewise min behavior).
